9 // Independent lossless block compression
10 // -------------------------------------
11 // The enclosing archive decides block boundaries and whether to encrypt.
12 // This module takes byte strings and has no file-system side effects.
13 // Original size and payload size are explicit in every encoded block.
14 // Original size is checked before reserving or reconstructing the output.
15 // Raw fallback uses a distinct ID, so decompression never guesses the codec.
16 // Both algorithms operate on bytes and preserve arbitrary binary input.
17 // Huffman describes a symbol distribution and a prefix-free bit stream.
18 // LZ77 describes already-seen byte sequences through backward references.
19 // Those are different algorithms; neither delegates to qCompress or zlib.
20 // Each block carries SHA256 of its original bytes to detect accidental damage.
21 // This checksum does not replace the keyed MAC of an encrypted archive.
22 // A decoder checks structural consistency before accepting that checksum.
23 // Forged lengths cannot expand output beyond the caller's configured bound.
24 // Trailing data, impossible references and nonzero padding are rejected.
25 // Deterministic encoding makes reproducible fixtures and comparisons possible.
26 // The hard 64 MiB cap also bounds encoder-side frequency and window resources.
27 // Normal repository chunks are 1 MiB and therefore below that cap.
28 // The format is versioned by the CVC1 magic; incompatible changes need a new
29 // version, not silently different meanings for an existing algorithm ID.
30 // See docs/algorithms.md for every header field and payload representation.
