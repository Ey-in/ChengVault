# 实施与验收记录

ChengVault由课程要求独立实现。此文件记录真实开发阶段，不代表已经获得课程分数。

## 已确立的要求

- Windows 10/11 x64、NTFS、C++20、Qt6、CMake/Ninja。
- 目录树备份恢复，NTFS链接、稀疏区间、ADS、属主/权限/时间。
- 六类课程筛选和四类附加筛选。
- PAX/TAR及索引归档，Huffman/LZ77，AES256/ChaCha20及认证。
- 加密块仓库、定时实时、网络账户隔离及增量。
- RS(12,10)归档纠错侧车。
- 原创源码注释超过20%，白盒测试，至少96例与8类测试。
- 模板报告DOCX/PDF、20页PPTX/PDF、3分钟内真实演示。

## 已实施并验证（2026-10-17）

1. CMake工程和隔离UCRT64工具链完成，生成GUI、CLI、Agent、Server四个程序。
2. 两套打包/解包、两套压缩/解压、两套密码加密/解密完成；标准密码向量与归档组合通过。
3. NTFS捕获恢复、六类必需及四类附加筛选、加密分块仓库、账户设备管理和加密增量网络完成。
4. Qt八页交互、定时实时任务、DPAPI本机密钥、独立后台进程和版本淘汰完成。
5. RS(12,10)独立实现完成：12种单片及66种双片擦除、文件级修复和错误拒绝实际通过。
6. Release核心测试591通过、0失败、0跳过；真实GUI20通过；独立后台进程5通过。
   合计616通过、0失败、0跳过，不重复累计覆盖率重跑或发布包重复测试。
7. 1GiB、5000小文件及超过4GiB稀疏文件实测完成；严格元数据恢复无警告，内容SHA-256一致。
8. 净开发工具PATH部署验证完成：真实GUI、加密备份恢复、独立Server、GUI和Agent工作流均通过。
   本验证仍在同一台机器进行，不能代替独立Windows环境复验。
9. 原创生产源码物理注释比例20.22%（1705/8433）；36个C++文件格式检查通过；cppcheck无错误/警告，
   保留7条经逐项说明的风格/性能建议。证据见evidence/quality。
10. 核心行覆盖率97.6%；原始GCC分支56.7%，排除编译器throw/unreachable边的辅助统计86.5%。
    项目不再设自选覆盖率合格线；不混用统计口径。最终原始计数、HTML和源码摘要见evidence/coverage。
11. 7张UML图及可编辑StarUML模型、模板报告、20页答辩PPT和2分58秒（178.18秒）真实演示视频已制作。
    最终文档逐页质量检查与文件清单随交付一起保存。
12. 路径、名字、扩展名与属主的通配匹配已独立实现解析和迭代回退，不调用Qt通配转正则或正则匹配引擎。
    已验证Unicode码点、字符集合、非法模式和复杂度上限；Qt只提供字符串容器和Unicode基础转换。
13. 本轮实际发现并修复PAX扩展头填充校验、Junction实际目标读取、后台坏配置隔离和重试/日志边界。
    发布进程测试还发现版本列表与淘汰并发竞争；公共列表读取现持有仓库锁，校验和淘汰在已持锁时
    复用私有读取函数，避免嵌套加锁。新增回归验证忙碌拒绝与释放后完整读取。
    覆盖率构建暴露GUI测试提前启动下一步的问题，测试改为等待完成回调；发布测试的任务状态轮询
    对原子替换期间短暂读失败执行有界重试。原失败记录保留在evidence/history。
14. 界面改为深色侧栏、暖白工作区、分组表单和原生矢量图标。20项GUI功能回归与32项额外交互观察通过；
    默认窗口1280×860、最小窗口1040×720和实际DPR3截图检查通过，屏幕字体记录随截图保存。
    9个核心/平台源文件哈希与之前覆盖率一致。发布包再次通过净PATH实测，报告与PPT同步新版界面。
    另附7页三人指南，按现有模块安排源码责任、接手验收、答辩与真实个人提交步骤。

## 明确的复验和实现边界

- 文件/目录符号链接已实际验收 PASS 2/0/0；历史 SKIP 保留在 evidence/history。
- 硬链接、Junction、稀疏文件、文件和目录ADS已实际验证；不把普通内容复制冒充类型恢复。
- 属主/组SID、DACL的ACE和保护/继承语义、时间属性已严格复验。Windows可能规范化DACL自动继承标志，
  不能认定安全描述符的所有控制位逐字节相同。
- 无VSS全目录瞬时快照；源文件变化会检测、失败或重试，不能保证业务数据库事务一致性。
- 自研密码遵循标准向量和认证封装，但未经过独立密码安全审计。
- StarUML模型通过官方元模型、ID、引用及父关系检查，并在官方StarUML 7.1.1原生程序中加载和导出7张图。
  验证使用不切换到用户桌面的隔离桌面。未注册软件的导出图带厂商水印，原样保留作打开证据；
  报告使用项目独立生成的清晰SVG/PNG，不能把带水印原生图当作出版质量验收通过。
- 第二台独立 Windows/NTFS 环境已完成当前机器复验（2026-10-21）；带权限符号链接 PASS（2026-10-23）；真实双机局域网 PASS_TWO_MACHINE_LAN（2026-10-25）。
